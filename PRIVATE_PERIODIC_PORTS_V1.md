## Admission and ordered stages

1. Native real input buffering asks the public plan. Detached source and stage preflight covers live/dead owner, due/not-due, marker present/absent, empty/low/full MP and admitted aim variants. Invalid programs refuse before MP/CD/cast count. Finite options and bounded capacities are checked. Restoration toggle-off preserves the existing direct API exception for deficient resources/recovery/silence; it still requires a valid public toggle plan.
2. Native committed cast debits fee once and captures actual cast aim/model. Public activate declares the status and, for Restoration, area. Selected source activation skips the original native ability switch. Cast IDs are single-use.
3. The original fighter buff phase observes the marker clock before native decrement. It retains actual key/object binding and the original latest-same-key query policy. Recast can leave two areas querying the newest same-key marker; it does not impose generation cancellation.
4. The original target fighter-DOT loop acquires an iteration lease. Host advances Maledict life/elapsed/tick once. Due pulse calls public onStage and native resolveDamage once, retaining dot/linaDone and remaining-life slow clamp. A due burst then receives fresh HP facts after that pulse and computes the existing public lost-HP formula; its hit resolves once. No capped fallback burst or extra catch-up loop is added. Source death retains the DOT, target death freezes its clocks as in Native. Strong dispel and ordinary lifetime filtering remain in their original phases.
5. The original ordered area loop acquires an area lease. Restoration advances the native life/age/tick using original live dt, then public onStage performs whole-dt mana upkeep before healing. The live mana delta immediately updates the detached source fact used by the callback. Empty/low MP, missing marker and owner death follow existing handler end decisions; mana zero never heals. The host removes the actual marker and area when requested. Owner death removes the area while retaining the native buff.
6. If a later zone (e.g. Death Ward) kills a Restoration owner and Native's final area filter removes an earlier area, area completion calls the existing dead-owner public stage with wholeDt0/pulseDuefalse. This records terminal owner-dead state without another resource debit, heal or clock advance. Toggle-off marks all same-owner same-ability areas cancelled before native removal. Unaccounted removal with a live owner is rejected.
7. Same-frame leased reentry is a no-op; unleased stage and repeated source calls fail without another effect. Pause/hitstop and all original stage ordering remain private.

## Minimal scoped resource ports

- damage(spec) validates the declared actor/target/ability, type, amount and original stage flags; it calls native resolveDamage exactly once and returns real accepted/landed/guarded/raw/actual/deferred/killedAtDebit. Public receipt replay never calls native damage.
- mana(spec) validates the owned source and finite delta; it commits the actual bounded native MP change once and returns that delta.
- heal(spec) validates the owned source/target/ability, requested amount and source label; it calls native heal exactly once and returns the authoritative actual/deferred receipt from the native HP path. Deferred capture and heal budgets are respected. No post-hit/post-heal estimate is used.
- status.list(...) returns one detached owned current marker view. status.remove(handle) and area.end(handle, reason) validate scoped handles and remove only their native owned state. Declarations never expose native object pointers.
